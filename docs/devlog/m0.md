# M0 开发笔记 · 初始化与环境验证（2026-09-11）

## 交付物

- 仓库骨架：`src/paper_agent/` 六模块包（sources / parsing / extraction / rag / graph / utils）+ `tests/`
- 配置体系：`config.yaml`（平台与流水线参数）+ `.env`（密钥，不入库）
- 验收命令 `pa doctor`：配置 → API Key → 平台连通 → LangGraph 图执行，四项自检
- 依赖：uv 0.12.12 管理，Python 3.13.2，53 包（langgraph 1.2.11 / typer / rich / openai 3.11.0）

## 实测结果

| 项 | 结果 |
|---|---|
| Embedding | BAAI/bge-m3 @ 硅基流动，热态 2.0s（首调 11.9s 为冷启动） |
| LLM | deepseek-ai/DeepSeek-V3 @ 硅基流动，0.6s |
| LangGraph | hello 图稳定执行，Windows 无坑 |

## 关键决策

1. **平台定稿**：主硅基流动（bge-m3 免费 + DeepSeek-V3 按量），智谱备选；两家均 OpenAI 兼容，切换只改 `config.yaml` 的 `base_url/model`。
2. **uv 用 `python -m uv` 调用**：本机 uv 不在 PATH，`python -m uv` 不依赖 PATH，README 快速开始已按此写。
3. **doctor 无 Key 时跳过而非报错**：平台项标「⏭ 未检查」并给出 Key 申请指引，图执行不受影响——保证 M0 代码先行可验收。
4. **git init 不自动提交**：提交时机由工作流约定控制（见 PLAN.md §12）。

## 踩坑记录

- 首次 embedding 调用 ~12s，易误判为超时故障；实为 BGE-M3 冷启动，复跑即降至 2s。后续解析/索引模块遇偶发慢调用，先想到冷启动。
- Windows 下 `ls` 不可用，验证命令用 `dir`。
